术语表 人名 / 专有名词的固定译法，翻译时强制遵守

钩子拿到的是游戏里的真实文本，最准确；OCR 模式识别的是屏幕上框选的区域（默认取窗口下部 34%，可在「翻译」面板里框选微调），需要系统安装「日语 OCR」组件。Textractor 的钩子覆盖率有限：TVP/KIRIKIRI（如 DRACU RIOT）用 GetTextExtentPoint32W 那条钩子通常没问题；WillPlus 这类引擎钩子常缺字，建议直接用 OCR 模式，或用 LunaTranslator。翻译沿用上方「简介翻译」里的 LLM 配置。日文原版强烈建议先用「⋯ → 转区启动…」开启转区再翻译：不转区时游戏产出的文本本身就是乱码，钩子拿到的也只能是乱码。
