# 四套主题 · 示例主页（+ 一个候选小样）

同一个内容（6 款游戏、同一套封面）用四种设计语言各做一遍 —— 给 P8.4「主题区分度」挑方向用。
四页都是**独立静态 HTML**：无构建、无 JS、无外链字体，双击 `index.html` 或直接开各目录下的
`index.html` 即可（`file://` 打开也正常，图片是相对路径）。

```
docs/theme-demos/
  index.html          四套的入口（并排预览）+ Atelier 候选卡
  aurora/             极光玻璃：毛玻璃 + 青紫光晕
  gallery/            展签式画廊：直角细线 + 衬线标题 + 目录编号
  screening/          夜间放映厅：暖黑 + 琥珀 + 节目单
  shelf/              收藏架：纸 + 木横档 + 黄铜卡片目录
  atelier/            Atelier 小样：浅粉工作台 + 纸片 + 和纸胶带（候选第 5 套）
  assets/             素材（见 CREDITS.md）+ 各主题的氛围图
  preview/            渲染出来的预览图（1600px 宽 JPEG，检查排版用）
```

## Atelier 小样（2026-09-23，反馈第 4 条）

`atelier/` 是**候选第 5 套主题**的小样，只用来「看方向」——还没有决定是做成第 5 套，
还是把它拿去改造收藏架。三件语言：

| 元素 | 做法 | 对应令牌 |
| --- | --- | --- |
| 浅粉工作台 | 玫瑰色桌面 + 极淡的**切割垫网格**（`repeating-linear-gradient` 两个方向），纯 CSS 不用位图 | `--desk` / 网格线 `rgb(150 100 120 / .055)` |
| 奶油纸片 | 纸面卡 + 玫红细边，**整体歪 -0.35°**；不靠投影立起来 | `--card #fffdfb` / `--rose-hair` |
| 和纸胶带 | 半透明暖粉条 + 白色细竖纹，`clip-path` 做两端撕口，左右各一段、角度不同 | `--tape` |
| 剪贴板 | 封面当「夹在板上的照片」：纸背 + 上缘一小段胶带，`nth-child` 交替 ±1° 错落 | `--rose` 选中描边 |
| 排印 | **楷体** + 衬线；标签像手写贴纸；分隔是玫红细线（不是黄铜） | `--serif` / `--rose` |
| 按钮 | 与另四套同一条扁平规则：主按钮玫红实色 50px、无渐变无投影；次按钮描边纸片 | `--rose` / `--on-rose` |

**还没做的**：区分度实测。现在 gallery–shelf 是 14.6（目标线 20），
Atelier 要么当第 5 套（主题矩阵从 25 张变 30 张，还要注册到 `core/theme.ts` 的 `THEMES`、
`visual.py` 的 `THEME_MATRIX`、`check_theme_contract.py` 与 `themes.spec.ts`），
要么改造收藏架 —— **先量一次真机区分度再定**（`tools/visual.py` + `visual_summary.py`）。
`preview/` 里也还没有它的预览图（生成预览要真机渲染）。

静态一致性（引用是否都存在、CSS 括号配平、关键结构齐不齐）由
`_sandbox/verify_demos_static.py` 离线校验，五个页面全过。

## v2：扁平化（2026-09-22 第二轮反馈）

使用者给的意见：**多做扁平化、少些体积感（尤其按钮）；关键卡片要大；关键按钮要显眼；
收藏架的底部木条取消或换成扁平元素；背景默认跟随当前游戏、可自定义常驻图；
主题用不同程度的颜色罩子压背景这个方向保留。** v2 就是按这几条改的：

| 条目 | v1 | v2 |
| --- | --- | --- |
| 按钮 | 渐变 + 发光投影 + 内高光（`linear-gradient` / `box-shadow` / `inset`） | **全部为 0**：主按钮 = 纯色块，次按钮 = 描边或纯文字（`_sandbox/element_flatness.py` 可复测） |
| 主按钮尺寸 | 38px 高、13px 字 | **50–55px 高、15.5px 字**，主色实心，一眼能看见 |
| 关键卡片 | 封面 236×354，标题 31px | 封面 **300×452**，标题 **46–54px**（编辑型展示字级） |
| 收藏架 | 木纹横档（4 层渐变 + 内高光 + 投影） | **取消**，换成 1px 黄铜基线 + 一排平刻度，封面直接立在线上 |
| 面板 | 投影 + 内高光 + 大模糊 | 半透明底 + **1px 细边**；v2 时只有 aurora 保留轻模糊，**v3 起四套一律不模糊** |
| 背景 | 固定一张氛围图 | **跟随当前游戏**（默认）/ **常驻图**，右上角开关可切（纯 CSS，能直接点） |

每页都跑了 DOM 自检（`_sandbox/verify_demos.py`，一次性工具）：无溢出、无裁切、
6 行列表齐全、主按钮背景是实色、标题字号与预期一致、背景开关两种状态都生效。

## v3：极光去模糊 + 常驻图可换（2026-09-22 第三轮反馈）

第三轮反馈只有两条，都是「把上一轮的取向推到底」：

| 条目 | v2 | v3 |
| --- | --- | --- |
| 极光玻璃的模糊 | 面板 `backdrop-filter: blur(16px)`，是四套里**唯一**保留模糊的（当时想留作主题身份） | **去掉**：面板只剩半透明底 + 1px 细边，跟另外三套一样平（`_sandbox/element_flatness.py` 可复测） |
| 常驻背景图 | 右上角开关只演示「跟随 / 常驻」两态，常驻那张写死在 HTML 里 | 开关切到常驻图时**多露出一个「更换常驻图…」入口**，并说明只支持一张；应用里对应「背景来源 + 更换/清除」 |

「跟随当前游戏」仍是默认态：切游戏就换壁纸。常驻图是**全局一张**（不是每游戏一张），
换一张就替换掉前一张——这也是应用里 `background_mode / background_custom` 两个设置的口径。

应用侧的落地（P8.3，同一轮）：

- 极光玻璃：`--fx-blur: 30px → 0px`，`aurora.skin.css` 里那条 `backdrop-filter` 整段删掉；
  `tokens.css` 的契约默认值也改成 0（默认主题就是极光，默认不放模糊）。
- 常驻背景：`config.DEFAULT_SETTINGS` 增加 `background_mode`（game / custom）、
  `background_custom`（`assets/backgrounds/persistent-*`）、`background_custom_scale`；
  背景面板顶部多了「背景 · 跟随当前游戏 / 背景 · 常驻图」两个胶囊，常驻态下多一行
  「更换图片… / 清除」；拖动缩放滑杆在常驻态写的是常驻图自己的缩放，不动游戏的。
  点缩略图 = 明确表达「还是跟着游戏走」，会先把模式切回来再应用。

## 参考：Gal Launcher 0.4.0 的三套主题

参考截图压在 `reference/`（1600px 宽的压缩副本；使用者的原图已按要求从 `docs/images/` 删除，
全分辨率版本没有备份）。读它们的**代码**（`Gal Launcher.exe` 里的 `app.asar`）
与**像素**（网格亮度、主色、平整度）得到的结论：

| 参考 | 字体 | 展示字级 | 圆角 | 扁平度（相邻像素差<6） | 主色 |
| --- | --- | --- | --- | --- | --- |
| editorial | Fraunces 衬线 + Inter Tight + JetBrains Mono | **62 / 46 / 40px** | 14–28px | 83% | 纸色 `#f3ead8`、墨 `#1d1410`、锈红 `#b8442a` |
| aurora | Manrope + Instrument Serif + Mono | 24px 以内 | 药丸 + 14–20px | 79% | 粉 `#fde7ee`、雾蓝 `#e6f1f9`、墨紫 `#3a2a3c` |
| atelier | Caveat 手写 + Press Start 2P + VT323 | 26px 以内 | 6px、圆片 | 70% | 桌面 `#efe3d4`、纸 `#fffaf4`、粉 `#e89cb4` |

对我们有用的三条：**展示字级要敢放大**（editorial 到 62px）、**按钮是「细边 + 半透明底」而不是渐变块**、
**线用墨色/强调色而不是浅灰**（`--rule: #1d1410`）。atelier 的立体感（内阴影模拟实体按键）
与这次的扁平方向相反，只借鉴它的「桌面 / 纸 / 胶带」配色意象。

## 每套改了什么（对照应用里的令牌）· v2

| 主题 | 字体排印 | 分隔与框架 | 封面呈现 | 背景处理 | 主要令牌 |
| --- | --- | --- | --- | --- | --- |
| 极光玻璃 | 无衬线；展示标题 **46px**、标签大写宽字距 | 1px 半透明细边；不做投影/内高光/**模糊**（v3 去掉） | 300×452 大卡片，1px 细边，圆角 14px | 青紫极光色罩 + 暗罩；面板半透明不模糊 | `--a-main #4fd6c4` / `--a-2` / `--hair` |
| 展签式画廊 | 衬线展示标题 **54px**；标签一律大写 + 宽字距 | 线用**墨色**（`--rule`），直角、无投影、无模糊 | 白卡纸 + 墨色细框（像裱起来的印刷品） | 去饱和提亮成「展墙」，罩子是纸色 | `--rule` / `--hair` / `--accent #b8442a` |
| 夜间放映厅 | 窄体无衬线，标题 **50px**；时间码等宽 | 琥珀细线贯穿；当前项左侧 3px 实心竖条 | 300×452 卡片 + 1px 琥珀边（**取消了光束/发光**） | 暖黑 + 琥珀色罩，图片压到只剩轮廓 | `--amber #e2a33c` / `--hair` |
| 收藏架 | 衬线标题 **42px**；卡片是纸面 | 黄铜细线 / 虚线表格线；**木横档换成 1px 基线 + 平刻度** | 封面直接立在基线上，当前那张用黄铜描边 | 纸色 + 木色罩，纸纹是极平的重复细线 | `--brass #b08a3e` / `--brass-hair` |
| Atelier（小样） | **楷体** + 衬线，标题 **43px**；标签像手写贴纸 | 玫红细线；纸片之间靠胶带与轻微歪斜分层 | 照片贴在剪贴板上（纸背 + 上缘胶带，±1° 错落） | 浅粉桌面 + 切割垫网格（纯 CSS） | `--rose #d4738e` / `--tape` / `--desk` |

按钮在各套里是同一套规则：**主按钮 50px 高、纯色实心、无渐变无投影；次按钮细边或纯文字**。
（Atelier 的 `.primary` 是玫红实色块，同样不渐变。）
四页的文字色都跑过对比度检查（`_sandbox/verify_demos.py` 量的是计算样式，不是肉眼）。

## 怎么用

1. 挑方向：四页并排看，圈出「哪些差别值得进应用」。
2. 落地：把选中的做法写进 `frontend/src/styles/themes/<style>.skin.css` —— 皮肤的限制是
   「**≤200 非空行**、选择器必须挂在自己的 `[data-style=…]` 下、圆角只能走 `--r-*` 令牌」
   （`tools/checks/check_theme_contract.py` 第 4/4.5/6 节 + `themes.spec.ts` 镜像）。
   本示例里的字体 / 分隔 / 封面处理正是靠这套结构性钩子搬进去的（P8.4–P8.10 已完成）。
3. 验收：改完跑 `python tools\visual.py`（主题矩阵截图基线要重录）与 `python tools\contrast.py`
   （对比度不达标会红）。
