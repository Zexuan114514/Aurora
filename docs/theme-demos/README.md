# 五套主题 · 示例主页

同一个内容（6 款游戏、同一套封面）用五种设计语言各做一遍 —— 给 P8.4「主题区分度」挑方向用。
五页都是**独立静态 HTML**：无构建、无 JS、无外链字体，直接打开 `index.html` 或各目录下的
`index.html` 即可（`file://` 打开也正常，图片是相对路径）。Atelier 已在 P8.17–P8.19 接入应用，
这里继续保留为独立设计参考。

```
docs/theme-demos/
  index.html          五套的入口（并排预览）
  aurora/             极光玻璃：毛玻璃 + 青紫光晕
  gallery/            展签式画廊：直角细线 + 衬线标题 + 目录编号
  screening/          夜间放映厅：暖黑 + 琥珀 + 节目单
  shelf/              收藏架：纸 + 木横档 + 黄铜卡片目录
  atelier/            Atelier：浅粉工作台 + 纸片 + 和纸胶带（正式第五套主题的设计来源）
  assets/             素材（见 CREDITS.md）+ 各主题的氛围图
  preview/            渲染出来的预览图（1600px 宽 JPEG，检查排版用）
                      + buttons-launch.jpg / buttons-hover.jpg（启动键对比）
```

## v4：按主题说明重做版面与皮肤（2026-09-23 晚）

这一轮的要求是：**各主题页面的布局与 CSS 要符合主题描述、走扁平化设计语言、有按键交互、尽量精美**。
五页的 HTML + CSS 全部重写（仍是静态、无构建、无 JS、无外链字体）。改完入口页与五张预览图一起重渲。

### 每页改了什么

| 主题 | 版面 | 皮肤要点 |
| --- | --- | --- |
| 极光玻璃 | 顶栏 / 大卡 / 列表 / 底条四块都改成**浮起来的玻璃面板**（圆角 22px + 1px 发丝边 + 20px 毛玻璃）；主卡右侧多一列「三格速览」把空场填住 | 面板底色改成**深蓝底衬**（`rgb(9 21 35 / .72)`）而不是白色高光。之前那版是 6% 白，玻璃会把亮壁纸整片提上来 —— 实测 hero 面板整块变成亮蓝，整页发蓝。换成深底衬后壁纸只透三成。青紫洗色 .24/.26 → .16/.18，`saturate` 190% → 145% |
| 展签式画廊 | 封面从「贴边」改成**裱在白卡纸里**（10px 衬边 + 1px 墨框），下面多一行小字说明；信息列加了「展签规格」三行（标签 / 值 + 细线） | 强调色由锈红 `#b8442a` 换成应用里那支**展墙蓝** `#2c4bd0`（浅色态 `--a-main`）—— 入口页的色块本来就写着蓝，两边终于对齐 |
| 夜间放映厅 | 主区改成「放映格 + 节目单」；三格速览走等宽数字 + 琥珀；节目单底部加一排**齿孔**收住空场 | 封面按应用的 `--fx-cover-shadow` 来：1px 琥珀环 + 深影，背后再垫一层琥珀晕（径向 .17）当「正在放映」的意思；时间码与数字一律等宽 |
| 收藏架 | 木横档回来了，但是**扁平的**：一条纯色木板（`#7a5636`，没有木纹渐变、没有内高光）+ 上沿 1px 黄铜基线 + 下沿一排平刻度；封面直接立在基线上 | 当前那张**往前挪 9px**（压在木板前缘）并描黄铜边 —— 用位移表达「抽出来」，替代 v2 取消掉的「接触暗影」 |
| Atelier | 封面从「一排整齐的」改成**摊在桌上的照片**：每张各自歪 −2.6°…+2.4°、高低错开 ±9px，hover 回正抬起；当前那张回正并描玫红边 | 切割垫网格做成**细线 20px + 粗线 100px** 两级（之前只有一级，几乎看不见）；胶带加宽、不透明度 .58 → .74 |

### 交互（五页统一补上）

- **启动键**：hover / active / focus-visible 三态齐全（各自的签名见下一节）
- **列表行**：hover 有一条从左侧长出来的强调色竖条（`height 0 → 42%`），当前项 62%
- **顶栏**：搜索框 `:focus-within` 变强调色、窗口按钮 hover 上底色（关窗是红的）、
  「背景 · 跟随当前游戏 / 常驻图」胶囊带一颗状态点
- 所有可点元素都有 `transition`，缓动统一用应用里的 `cubic-bezier(0.32, 0.72, 0, 1)`
- 装饰性动效只留三处：极光的光带、放映厅的呼吸灯、运行中指示点的脉冲

### 扁平化的边界

使用者要「少些体积感」，可主题描述里又写着「光晕 / 内阴影」。这一轮划的线是：

- **按钮一律扁平**：主按钮纯色块、无渐变、无投影；次按钮描边或纯文字 —— 五页都守住了
- **主题身份可以留一点点「非扁平」**：极光的玻璃模糊与封面外圈、放映厅的呼吸辉光、
  收藏架启动键的压印书脊、Atelier 印章的油墨颗粒。这些是「这套主题之所以是这套主题」的东西，
  抹掉之后五套会开始长得一样
- 收藏架的木横档按 v2 的要求**换成扁平元素**（纯色木板），没有回到 v1 的木纹渐变

### 与应用侧的关系

主项目的 UI 这半年改得多，示例页已经落后了。这一轮把两边对齐了几处：

- 极光玻璃的模糊**回到示例页** —— 应用 P8.8 把 `--fx-blur` 放回 20px（只留极光一套），
  示例页 v3 曾把它整层去掉
- 画廊强调色对齐应用的展墙蓝（浅色 `#2c4bd0` / 深色 `#3f63e8`）
- 封面处理对齐应用的 `--fx-cover-shadow`：放映厅是琥珀环 + 深影、极光是柔影、画廊无影
- 圆角口径对齐各主题的 `--r-*`：极光 22/16/11、画廊一律 1px、放映厅 4/3/2、收藏架 4/2

## 启动键：五套各自的语言（2026-09-23）

参考 [gal-launcher](https://github.com/KamiNeko-pre/gal-launcher) 的做法看了一遍：
他们把「启动」当成整套主题的仪式核心 —— Arcade 的 START 是全屏唯一**可下压 + 呼吸灯**的键，
Atelier 的 play-stamp 是全页唯一**正圆红印章**，靠「形状 / 颜色 / 描边 / 光影 / 质感 / 姿态」
六重差异把它从普通按钮里拎出来。下面这五套按同一思路自己设计（**没有抄他们的实现**）。

**五套共用同一份 DOM**（这是 ADR-0013 的架构原则：多套皮肤一份标记），差别全在各自的 `style.css`：

```html
<button class="play" type="button">
  <i class="play-ic" aria-hidden="true"></i>
  <span class="play-lb">开始游戏</span>
  <span class="play-sub">ENTER</span>
</button>
```

| 主题 | 一句话 | 形状 | 光影 | 动效 |
| --- | --- | --- | --- | --- |
| 极光玻璃 | **一条会流动的极光光带** | 胶囊 58px | 内部斜向青→紫渐变带；hover 撑开青色外发光 | 光带常驻缓慢横移（5.2s），hover 提速到 1.9s |
| 展签式画廊 | **盖在展签上的印章** | 直角矩形 | 墨色外框 + 内缩 5px 的第二道细框；hover **整块反白**（墨底纸字）、内框收紧到 9px | 左侧竖排编号 `01`；按下沉 1px |
| 夜间放映厅 | **放映机点亮** | 琥珀实色块 56px | 左侧一颗灯珠（径向渐变 + 白芯）+ 下缘 3px 时间码刻度；常驻极轻呼吸辉光 | 呼吸 2.6s；hover 停住呼吸、辉光撑到最亮 |
| 收藏架 | **一册线装书** | 黄铜实色块 54px | 左侧 14px 深色「书脊」带缝线；压印内阴影（上白下暗） | hover 整块**向右抽出 3px**（像把书从架上抽出来）；按下再沉 1px |
| Atelier | **压进纸里的红印章** | 正圆 138px | 双层白描边 + 玫红光晕 + 大投影 + 油墨颗粒（`repeating-conic-gradient`）；外圈撒一圈**不规则油墨飞溅** | 常驻歪 7°，hover **回正 + 放大 1.06**；按下缩到 0.97 |

五套里只有 Atelier 是正圆、只有极光是胶囊、只有画廊会反白、只有放映厅带灯、只有收藏架有书脊 ——
把 `preview/buttons-launch.jpg` 和 `buttons-hover.jpg` 并排一看就分得清。

次级按钮（背景图 / 详情）沿用各主题原本的 ghost 规则：画廊是下划线式、极光是半透明填充、
放映厅与收藏架是纯文字、Atelier 是淡玫红填充。

### 可读性实测（离线，不靠肉眼）

按钮好看不等于看得清 —— 项目在 P8.3 就栽过一次（深色面板把正文压到 1.04）。
所以这五个启动键也量了对比度：headless Chromium 渲染 + WCAG 相对亮度，
取**文字左右紧邻处的背景中位色**（中位数不受抗锯齿碎像素与装饰线影响），
阈值按项目口径 —— 正文 ≥4.5、大字（≥24px，或 ≥18.66px 且 ≥700）≥3.0。
脚本 `_sandbox/check_demo_button_contrast.py`，可随时复跑。

| 主题 | 主标签 | 图标 | 副标签（ENTER） |
| --- | --- | --- | --- |
| 极光玻璃 | 8.46 | 16.96 | 8.66 |
| 展签式画廊 | 15.91 | 15.91 | 15.91 |
| 夜间放映厅 | 8.39 | 8.88 | 8.39 |
| 收藏架 | 5.34 | 5.34 | 5.34 |
| Atelier | 5.34 | 4.60 | 5.38 |

（上表是 **v4 重测**的结果。极光玻璃 6.15 → 8.46 是因为启动键底色从 74% 提到 82% 不透明、
光带 alpha 降到 .5/.54；画廊 16.41 → 15.91 是因为展墙底从 `#f4f1ea` 换成应用的 `#ebeae5`，
仍在 15 以上。Atelier 的图标 4.60 依旧最贴线 —— 动那个印章的颜色前记得复跑一次。）

**这一测抓到并修掉一个真问题**：Atelier 的印章原来是浅玫红（`#e2899f → #d4738e`），
白字压在上面只有 **2.45–2.73** —— 大字勉强、小字（9.5px 的 ENTER）根本读不清。
改成朱砂色阶（`#b8506c → #9c3f5a → #6d2537`）后升到 4.60–5.34，
顺带更像真印章：**印章本来就该比桌面上的玫红深一档**，浅的那版是「粉圆饼」不是「印」。

五套里画廊最稳（16.41，纸白底 + 墨字），Atelier 的图标 4.60 最贴线 ——
再调浅一点就会掉到 4.5 以下，改这个印章的颜色时记得复跑一次。

## Atelier 设计来源（2026-09-23，反馈第 20 条）

`atelier/` 是**第五套正式主题**的独立设计来源。应用已在 P8.17–P8.19 接入它的令牌、
皮肤与按钮；这里保留三件语言的静态说明：

| 元素 | 做法 | 对应令牌 |
| --- | --- | --- |
| 浅粉工作台 | 玫瑰色桌面 + 极淡的**切割垫网格**（`repeating-linear-gradient` 两个方向），纯 CSS 不用位图 | `--desk` / 网格线 `rgb(150 100 120 / .055)` |
| 奶油纸片 | 纸面卡 + 玫红细边，**整体歪 -0.35°**；不靠投影立起来 | `--card #fffdfb` / `--rose-hair` |
| 和纸胶带 | 半透明暖粉条 + 白色细竖纹，`clip-path` 做两端撕口，左右各一段、角度不同 | `--tape` |
| 剪贴板 | 封面当「夹在板上的照片」：纸背 + 上缘一小段胶带，`nth-child` 交替 ±1° 错落 | `--rose` 选中描边 |
| 排印 | **楷体** + 衬线；标签像手写贴纸；分隔是玫红细线（不是黄铜） | `--serif` / `--rose` |
| 按钮 | 与另外四套同一条扁平规则：主按钮玫红实色 50px、无渐变无投影；次按钮描边纸片 | `--rose` / `--on-rose` |

**当前状态**：Atelier 已注册到 `core/theme.ts` 的 `THEMES`、`visual.py` 的 `THEME_MATRIX`、
`check_theme_contract.py` 与 `themes.spec.ts`；浅色也已纳入矩阵，当前主题矩阵为 35 张，
区分度为 23.9。预览图保留在 `preview/atelier.jpg`（headless Chromium 渲染）。

静态一致性（引用是否都存在、CSS 括号配平、关键结构齐不齐、启动键三部件在不在）
由 `_sandbox/verify_demos_static.py` 离线校验，五个页面全过。

## v2：扁平化（2026-09-22 第二轮反馈）

使用者给的意见：**多做扁平化、少些体积感（尤其按钮）；关键卡片要大；关键按钮要显眼；
收藏架的底部木条取消或换成扁平元素；背景默认跟随当前游戏、可自定义常驻图；
主题用不同程度的颜色罩子压背景这个方向保留。** v2 就是按这几条改的：

| 条目 | v1 | v2 |
| --- | --- | --- |
| 按钮 | 渐变 + 发光投影 + 内高光（`linear-gradient` / `box-shadow` / `inset`） | **全部为 0**：主按钮 = 纯色块，次按钮 = 描边或纯文字（`_sandbox/element_flatness.py` 可复测） |
| 主按钮尺寸 | 38px 高、13px 字 | **50–55px 高、15.5px 字**，主色实心，一眼能看见 |
| 关键卡片 | 封面 236×354，标题 31px | 封面 **300×452**，标题 **46–54px**（编辑型展示字级） |
| 收藏架 | 木纹横档（4 层渐变 + 内高光 + 投影） | **取消**，换成 1px 黄铜基线 + 一排平刻度，封面直接立在线上 |
| 面板 | 投影 + 内高光 + 大模糊 | 半透明底 + **1px 细边**；当前五套里只有 aurora 保留模糊，其余主题不模糊 |
| 背景 | 固定一张氛围图 | **跟随当前游戏**（默认）/ **常驻图**，右上角开关可切（纯 CSS，能直接点） |

每页都跑了 DOM 自检（`_sandbox/verify_demos.py`，一次性工具）：无溢出、无裁切、
6 行列表齐全、主按钮背景是实色、标题字号与预期一致、背景开关两种状态都生效。

## v3：极光去模糊 + 常驻图可换（2026-09-22 第三轮反馈）

第三轮反馈只有两条，都是「把上一轮的取向推到底」：

| 条目 | v2 | v3 |
| --- | --- | --- |
| 极光玻璃的模糊 | 面板 `backdrop-filter: blur(16px)`，是五套里**唯一**保留模糊的（作为主题身份） | 应用当前保留极光 20px 模糊；其余四套走半透明底 + 细边（`_sandbox/element_flatness.py` 可复测） |
| 常驻背景图 | 右上角开关只演示「跟随 / 常驻」两态，常驻那张写死在 HTML 里 | 开关切到常驻图时**多露出一个「更换常驻图…」入口**，并说明只支持一张；应用里对应「背景来源 + 更换/清除」 |

「跟随当前游戏」仍是默认态：切游戏就换壁纸。常驻图是**全局一张**（不是每游戏一张），
换一张就替换掉前一张——这也是应用里 `background_mode / background_custom` 两个设置的口径。

应用侧的落地（P8.3，同一轮）：

- 极光玻璃：`--fx-blur: 30px → 0px`，`aurora.skin.css` 里那条 `backdrop-filter` 整段删掉；
  `tokens.css` 的契约默认值也改成 0（默认主题就是极光，默认不放模糊）。
- 常驻背景：`config.DEFAULT_SETTINGS` 增加 `background_mode`（game / custom）、
  `background_custom`（`assets/backgrounds/persistent-*`）、`background_custom_scale`；
  背景面板顶部多了「背景 · 跟随当前游戏 / 背景 · 常驻图」两个胶囊，常驻态下多一行
  「更换图片… / 清除」；拖动缩放滑杆在常驻态写的是常驻图自己的缩放，不动游戏的。
  点缩略图 = 明确表达「还是跟着游戏走」，会先把模式切回来再应用。

## 参考：Gal Launcher 0.4.0 的三套主题

参考截图压在 `reference/`（1600px 宽的压缩副本；使用者的原图已按要求从 `docs/images/` 删除，
全分辨率版本没有备份）。读它们的**代码**（`Gal Launcher.exe` 里的 `app.asar`）
与**像素**（网格亮度、主色、平整度）得到的结论：

| 参考 | 字体 | 展示字级 | 圆角 | 扁平度（相邻像素差<6） | 主色 |
| --- | --- | --- | --- | --- | --- |
| editorial | Fraunces 衬线 + Inter Tight + JetBrains Mono | **62 / 46 / 40px** | 14–28px | 83% | 纸色 `#f3ead8`、墨 `#1d1410`、锈红 `#b8442a` |
| aurora | Manrope + Instrument Serif + Mono | 24px 以内 | 药丸 + 14–20px | 79% | 粉 `#fde7ee`、雾蓝 `#e6f1f9`、墨紫 `#3a2a3c` |
| atelier | Caveat 手写 + Press Start 2P + VT323 | 26px 以内 | 6px、圆片 | 70% | 桌面 `#efe3d4`、纸 `#fffaf4`、粉 `#e89cb4` |

对我们有用的三条：**展示字级要敢放大**（editorial 到 62px）、**按钮是「细边 + 半透明底」而不是渐变块**、
**线用墨色/强调色而不是浅灰**（`--rule: #1d1410`）。atelier 的立体感（内阴影模拟实体按键）
与这次的扁平方向相反，只借鉴它的「桌面 / 纸 / 胶带」配色意象。

## 怎么用

1. 挑方向：四页并排看，圈出「哪些差别值得进应用」。
2. 落地：把选中的做法写进 `frontend/src/styles/themes/<style>.skin.css` —— 皮肤的限制是
   「**≤200 非空行**、选择器必须挂在自己的 `[data-style=…]` 下、圆角只能走 `--r-*` 令牌」
   （`tools/checks/check_theme_contract.py` 第 4/4.5/6 节 + `themes.spec.ts` 镜像）。
   本示例里的字体 / 分隔 / 封面处理正是靠这套结构性钩子搬进去的（P8.4–P8.10 已完成）。
3. 验收：改完跑 `python tools\visual.py`（主题矩阵截图基线要重录）与 `python tools\contrast.py`
   （对比度不达标会红）。
