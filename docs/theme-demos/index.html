五套主题 · 示例主页

同一个内容（6 款游戏、同一套封面）用五种设计语言各做一遍，用来挑方向、对比「主题该怎么不一样」。 每页都是独立的静态 HTML（无构建、无 JS、无外链字体），直接打开即可； 素材出处见 assets/CREDITS.md。五页与 ADR-0013 的语义令牌一一对应， 落地时按 --s-base / --s-panel / --text-* / --a-* / --ln* 往皮肤层搬。
最后一页是 Atelier（正式第五套，反馈第 20 条）——这里保留为独立设计参考， 应用接入与五套按钮皮肤已在 P8.17–P8.19 完成。
v4 精修（2026-09-23）：版面与皮肤按各主题的文字说明重做了一遍 —— 扁平化设计语言、 统一的 hover / active / focus-visible 交互、五套各自成体系的启动键。 详细的改动清单与可读性实测见 README.md。

Aurora
极光玻璃Glass · 默认

毛玻璃 + 青紫极光：面板是半透明玻璃（20px 模糊、深蓝底衬），大圆角、青紫光斑；启动键是一条会流动的极光光带。
Gallery
展签式画廊Wall label · 直角细线

界面退成展签：直角、1px 墨线、衬线大标题（54px）；封面裱在白卡纸上，目录编号化。启动键是盖在展签上的印章，hover 整块反白。
Screening
夜间放映厅Warm black · 琥珀

暖黑 + 琥珀：当前封面是正在放映的那一格（琥珀细边 + 背后一层琥珀晕），右侧是等宽时间码的节目单。启动键是一台点亮的放映机。
Shelf
收藏架Paper · 木与黄铜

纸 + 木横档 + 黄铜：封面立在一条扁平木板上（上沿黄铜基线、下沿平刻度），当前那张往前挪一格；说明是纸质卡片，列表是黄铜卡片目录。
Atelier
Atelier第五套 · 粉桌 / 纸片 / 胶带

浅粉工作台 + 奶油纸片 + 和纸胶带：说明是贴了胶带的纸片，封面像摊在桌上的照片（各自歪一点、高低错开）；启动键是压进纸里的红印章。应用已在 P8.17–P8.19 接入这套主题与独立按钮皮肤。
