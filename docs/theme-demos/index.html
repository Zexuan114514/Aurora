四套主题 · 示例主页

同一个内容（6 款游戏、同一套封面）用四种设计语言各做一遍，用来挑方向、对比「主题该怎么不一样」。 每页都是独立的静态 HTML（无构建、无 JS、无外链字体），直接双击打开即可； 素材出处见 assets/CREDITS.md。四页与 ADR-0013 的语义令牌一一对应， 落地时按 --s-base / --s-panel / --text-* / --a-* / --ln* 往皮肤层搬。
最后一张是 Atelier 小样（候选第 5 套，反馈第 4 条）——只用来「看方向」， 要不要做成第 5 套、还是拿去改造收藏架，要先有一组真机区分度数据才好定。
