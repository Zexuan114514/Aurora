# Aurora 1.0.0

发布日期：2026-09-27

## 新增

- 本地游戏库、封面环形大厅、分类页和五套主题。
- VNDB、Bangumi、Steam 等公开资料源的匹配与简介翻译。
- Locale Emulator 转区启动，以及游戏内逐句翻译的置顶悬浮窗。
- 可扩展的资料源 / 翻译引擎插件接口与引擎规则包。

## 改进与修复

- 分类页支持批量分类、封面选择反馈，以及左键切换游戏、右键操作菜单。
- 翻译面板显示当前线程、H-code、最近提取文本和找钩子结果。
- 前端主题按钮、悬浮翻译窗、输入框对比度和小窗口滚动体验已统一。
- Windows 打包文件包含 Aurora 的产品与版本信息。

## 下载与更新

请从 [GitHub Releases](https://github.com/Zexuan114514/Aurora/releases/tag/v1.0.0) 下载 `Aurora.exe`。
这是未签名的 Windows 程序，系统可能显示“未知发布者”提示；请核对同目录下的 `Aurora.exe.sha256` 后再运行。

源码运行、前端构建、引擎规则和插件贡献方式见 [README](../../README.md)、[手册](../manual/README.md) 与 [贡献指南](../../CONTRIBUTING.md)。
